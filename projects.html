ai-biotech

Protein structure analysis · audited dataset and internal baseline Public
Public Stages 1–11 complete Stage 8.2 benchmark locked No external validation

An early-stage AI for Biotechnology (AI4Bio) research project in computational biology. It starts from protein sequences and AlphaFold structures, extracts documented residue-level features, and carries the result through an audited dataset, a frozen benchmark, an internally evaluated LightGBM baseline, and a runnable inference CLI. The emphasis is on data provenance, reproducibility, and clearly stated limits — not on claiming biological results.

The current benchmark uses a concrete residue-level target: whether a residue is annotated as a UniProt active or binding site (A+B). The stack is deliberately small and inspectable: Python, Biopython, pandas, NumPy, matplotlib, scikit-learn, XGBoost, LightGBM, and SciPy. Training and evaluation run on a standard machine without a GPU.

The runnable artifact

Stage 11 retrained the selected configuration on all 55,503 rows and exported results/models/golden_lightgbm_12a.joblib (157,432 bytes) with a sigmoid calibrator. The predict.py CLI accepts a UniProt accession — fetching and verifying the AFDB v6 structure and PAE — or a local CIF/PDB structure plus PAE JSON. It writes probability_raw, probability_calibrated, and predicted_active_binding.

On P02144, extracted features agreed with the training dataset to 3.55e-15 and probabilities were bit-identical. P00520 confirmed the same pipeline on a longer sequence (1,123 aa). Both are training proteins, so this is pipeline evidence, not biological validation. The 0.5 threshold is a display convention; it produced no positive calls on either test.

What this project is not

Stated plainly, because the distinction matters: this is now a data, benchmarking, and internal modelling project. It is still not a finished drug-discovery system or a validated predictor. None of the following exist yet, and none are claimed:

  • No external validation. The deployed model and calibrator were fitted on the same 102 proteins used for feature, radius, and model selection. Stage 11 is deployment, not validation.
  • No generalizable predictive model. The internal LOGO metrics are not evidence that the model works on new proteins.
  • No biological finding or wet-lab validation. Predictions are not evidence of function, and no experimental validation exists.
  • No docking, molecular dynamics, or compound screening. The project is residue-level structure analysis and benchmarking only.
  • No experimental structural ground truth. Predicted structures are the only structural input; there is no comparison against experimental (PDB) structures.
  • No validated decision threshold. The 0.5 cutoff is a display convention; a biological threshold would need labelled external data.

Known limitations

  • Imbalanced, clustered data. The set has 55,503 residues but only 955 positives (1.72%). Residues within a protein are strongly correlated, and 24 proteins have no positive residues, so only 78 of 102 LOGO folds are evaluable. The row count is not an independent-sample count.
  • Internal evaluation only. Feature choice, radius, model, and calibrator were selected on the same 102 proteins. Nested LOGO-CV lowers median PR-AUC to 0.1550 and the pooled gain to 4.55×, but it is still not external validation.
  • One protein excluded. P11532 was removed because the AFDB entry used a 525-aa isoform, not the 3,685-aa canonical sequence. The clean set is 102 proteins and no replacement was added.
  • Prediction-only, single-chain inputs. The dataset stores AlphaFold predictions only, with no complexes, ligands, or post-translational modifications. The spatial features are collinear with the frozen features; 12 Å is the edge of the tested grid, not a proven global optimum. Full ablation, importance-stability tests, and radii above 12 Å have not been run.
  • Narrow inference contract. The CLI requires one chain, residue numbering 1..N, pLDDT in the B-factor column, and an N×N PAE matrix, with no imputation. Experimental PDB files generally do not meet those conditions and are unsupported. AFDB versions other than v6 only trigger a distribution-shift warning.
  • Packaging and testing gaps. The model artifact is a joblib pickle, so it should only be loaded from a trusted source. Stage 11's end-to-end tests were run in a separate test harness and are not committed as a test suite.

Note on confidence scores. pLDDT, PAE, and pTM measure a model's internal confidence — not biological truth. A high-confidence prediction can still be wrong, and verifying a structure requires real experiments such as X-ray crystallography, NMR, or cryo-EM. Nothing in this project should be read as experimentally validated.

melanin-biotech

In Silico Reengineering of Radiosynthetic Pathways · fungal melanin and radiation Pipeline complete
Public Core pipeline runs end-to-end In silico only No experimental validation

A computational study of the radiotrophy hypothesis: whether fungal melanin can absorb ionizing radiation and pass that energy into metabolism. The project uses Cladosporium sphaerospermum — the dark-pigmented fungus grown on the International Space Station — as a template, and asks the smaller, testable question rather than assuming that fungi “eat radiation”.

It builds a reduced stoichiometric model of the DHN-melanin and DOPA-melanin pathways, checks whether key pathway enzymes have detectable orthologs in the C. sphaerospermum genome, and runs a geometry and docking pilot before staging molecular dynamics and DFT steps. Every stage separates what the data support from what remains a hypothesis.

What this project is not

  • No experimental validation. Every number is an in silico estimate; no biological claim or engineering application follows from it.
  • No production MD or DFT. The pipeline prepares OpenMM systems and stages ORCA inputs; neither simulation has been run.
  • Not a genome-scale model. The FBA model is a reduced stoichiometry with placeholder biomass and maintenance reactions, not measured parameters for C. sphaerospermum.
  • No claim that fungi “eat radiation”. The radiotrophy hypothesis is debated; the project tests it step by step rather than assuming it.
  • No true target structures or affinities. Docking uses PDB homolog surrogates (1GW0 for laccase, 8CG4 for PKS1), and Vina scores are not binding affinities.
  • Homology is not function. tblastn hits are sequence evidence only; they do not show expression or involvement in the melanin pathway.
  • The Marcus model is narrow. A single-electron outer-sphere treatment does not automatically represent physiological NAD+/NADP+ hydride transfer or pH-dependent PCET.

Note on the data. NCBI does not yet provide a complete annotated DHN-melanin gene set for C. sphaerospermum; only two partial type III PKS sequences are direct, and the rest are reference orthologs. The project records that distinction rather than blurring it.
