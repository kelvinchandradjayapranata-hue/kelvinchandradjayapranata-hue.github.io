What this page can show

The public Atlas API returns VERIFIED records by default. This page asks explicitly for PENDING records as well, because the pilot is still under human review, and labels every result. PENDING means awaiting review, not verified. DEMO, REJECTED, UNKNOWN, and INFERRED records are not part of the public surface.

How to read the evidence states

VERIFIED means a reviewer accepted an accessible source and a stable external identifier. PENDING means the record was imported from public metadata and is still awaiting human review. A PENDING badge is never a claim of verification.

Metadata is public OpenAlex data (CC0). The Atlas removes raw affiliation evidence, ORCIDs, author contact fields, review notes, and acquisition paths from this public view.
